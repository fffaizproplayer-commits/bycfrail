API Documentation
POST /api/bypass Solve Turnstile
Request Body
url string Target website URL
sitekey string Cloudflare Turnstile sitekey
Example Request
curl -X POST https://your-domain.vercel.app/api/bypass \
  -H "Content-Type: application/json" \
  -d '{"url":"https://target.com","sitekey":"0x4AAAA..."}'
Example Response
{
  "success": true,
  "token": "0.eyJhbGciOiJSUzI1NiJ9..."
}

JS Usage in Code 
const res = await fetch('/api/bypass', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    url: 'https://target.com',
    sitekey: '0x4AAAAAAA...'
  })
});

const { token } = await res.json();
console.log(token);
